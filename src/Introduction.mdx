# Portfólio NerdStarCode: componentes

Componentes do site organizados em **Atomic Design**. Cada componente fica em
`src/components/<tier>/<Nome>/` com:

| Arquivo           | Conteúdo                                              |
| ----------------- | ----------------------------------------------------- |
| `Nome.tsx`        | componente (export nomeado + `default`)               |
| `Nome.stories.tsx`| stories CSF3 com `autodocs` e pelo menos um `play`    |
| `Nome.test.tsx`   | testes Vitest + Testing Library (`describe/it` em PT) |
| `index.ts`        | reexporta o componente                                |

## Tiers

- **Atoms**: sem estado e sem compor outros componentes do projeto (`NavLink`, `Container`, ícones).
- **Molecules**: composição pequena, um callback ou leitura de contexto com fallback por props (`LanguageSwitcher`, `ProjectCard`).
- **Organisms**: estado real, efeitos (router, three.js) ou composição de moléculas (`NavBar`, `ProjectsGrid`).
- **Templates**: a casca das páginas (`PageLayout`).
- **Pages** (`src/pages`): apenas compõem organisms com os dados de `src/data`.

Componentes que dependem de contexto (idioma, tema, área) aceitam **props opcionais** que têm
prioridade sobre o contexto (`prop ?? contexto ?? padrão`). Assim dá para usá-los isolados em stories e testes.

## Toolbar

Use **Idioma** (pt/en/es) e **Tema** na barra superior: todas as stories são envolvidas pelos mesmos
providers do `_app`.
